# 20261014 更新说明

## 更新重点

- 升级至 vLLM 0.31 开发基线，完成 PrivateUse1 profiler、compile/AOT、MRV2、采样及插件接口适配。
- 更新 Qwen GDN 的显式状态/metadata 接入、DFlash2 输入准备与 placeholder 处理，修复滑窗取数及原地卷积状态写回。
- torch_mcpu 适配 PyTorch 2.13 的编译头文件、profiler 与 vLLM kernels，修复 lazy-view/stride 拷贝；torch_mpi_ext 新增 out-of-place all-reduce。
- DFlash/DFlash2 context KV：使用模型自身 RoPE 并接收返回的 K，跳过空 context，在 v_scale 后通过可选 grouped hook 写 cache；插件持续检查 backend、dtype、layout、对齐与 cache 区域不重叠，不满足条件或处于 Dynamo tracing 时按层有序回退。vLLM `5ac46306e986e06339d0259933b0357884f82dc8` 与插件 `327a83c12ea1af78f1f1d1b0faaba2b6e1a55ed3` 配套交付；本次未改 torch_xcpu 的 launch impl。
- 算子团队优先阅读下方“影响 mcpu launch impl”的计算段；不改变从核的包装、校验与组合接口单独列出。

模型支持情况：

- Qwen3.5/3.6/3.8 + DFlash/DFlash2 适配完成
- GLM5.2 尚未适配完成
